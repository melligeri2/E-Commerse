# PS Ecommerce Website

PS Ecommerce is a responsive E-Commerce website developed using HTML, CSS, and JavaScript.

## Features
- User Registration and Login
- Product Search
- Product Filtering and Sorting
- Wishlist Management
- Shopping Cart
- Quantity Update
- QR Code Checkout
- Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Pages
- Home Page
- Shop Page
- About Us
- Contact Us
- Sign Up
- Sign In

## Future Improvements
- Spring Boot Backend
- MySQL Database
- Payment Gateway Integration
- Admin Dashboard
